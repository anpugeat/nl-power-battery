# Netherlands Battery Project - WIP

Currently in progress. The project uses four conventions:

1.  All timestamps are stored in UTC. Amsterdam time is used only to define the delivery day and the cut-off.
2.  Everything is hourly. Quarter-hour prices are averaged to hourly.
3.  The forecast cut-off is 11:00 Amsterdam time on the day before delivery.
4.  Data starts 1 January 2024. Tuning uses 2024 only. The test period starts 1 January 2025.
